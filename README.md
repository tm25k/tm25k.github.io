# Tabu | Virology Research

A responsive, static research portfolio ready for GitHub Pages. No build tools are needed.

## Personalize before publishing

Edit `index.html`:

1. Replace the introductory and About copy with Tabu's exact biography, affiliation, position, and research focus.
2. Replace the broad research cards with her actual areas of expertise.
3. Replace the projects placeholder with verified project titles, her role, collaborators, summaries, and links.
4. Replace the publications placeholder with complete citations and DOI or publisher links. Do not claim work as published without verification.
5. Replace both `hello@example.com` email links and the contact note with her preferred public contact details. The placeholder email is intentionally disabled in `script.js`.
6. Update the page description and title if her full name or preferred title differs. Add a photo only with permission and appropriate rights.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the **contents** of this folder to its root, including `index.html`, `styles.css`, and `script.js`.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. GitHub will show the published URL on the Pages settings screen. For a project repository, the URL normally has the form `https://USERNAME.github.io/REPOSITORY/`.

The site uses relative asset paths, so it works under either a project URL or a custom domain. For local preview, open `index.html` in a browser. Google Fonts require an internet connection; system fonts are used as fallback.
